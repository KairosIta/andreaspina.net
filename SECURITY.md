# Sicurezza / Security

## Segnalare una vulnerabilità / Reporting a vulnerability

Non pubblicare vulnerabilità, credenziali o dettagli sfruttabili nelle issue.
Invia la segnalazione tramite il
[canale privato di GitHub](https://github.com/KairosIta/andreaspina.net/security/advisories/new).

Do not disclose vulnerabilities, credentials, or exploitable details in
public issues. Submit the report through
[GitHub's private channel](https://github.com/KairosIta/andreaspina.net/security/advisories/new).

Una segnalazione utile include:

A useful report includes:

- componente e versione interessati / affected component and version;
- impatto osservato / observed impact;
- passaggi minimi per riprodurre il problema / minimal reproduction steps;
- eventuale mitigazione proposta / suggested mitigation, if available.

## Versioni supportate / Supported versions

La versione supportata è quella presente sul branch predefinito `main`. Le
revisioni precedenti non ricevono correzioni separate.

The supported version is the one on the default `main` branch. Older
revisions do not receive separate fixes.

Le segnalazioni vengono prima validate in privato. I dettagli vengono resi
pubblici soltanto quando esiste una correzione o una mitigazione adeguata.

Reports are first validated privately. Details are disclosed only after an
appropriate fix or mitigation is available.
